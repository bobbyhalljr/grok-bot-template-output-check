# Grok Bot template output check

Independent TypeScript teaching example, not an official template export, SDK, or Grok Bot integration. Fictional example.com data only. Requires Node >=22.18. Run `npm test` and `npm run demo`. No dependencies, network calls, credentials, or external mutations.

`ready` means the local contract passed. It does not prove the claims or linked content are true. Source matching is by declared checked origin, not a repository-level authorization check. Checked-at is supplied data, not a trusted audit record. `partial` means all structural checks passed but a required source was explicitly unavailable. `invalid` means the contract or output failed a check. The release window includes both endpoints. An item cap is an output limit, not a cost or execution limit.

Strings are accepted as timezone-qualified ISO timestamps parseable by JavaScript; the example is not a full calendar-date validator. No static type-check was run; Node executes TypeScript by stripping supported type syntax. Production systems need schema validation, source verification, trusted timestamps, access control, and actual enforcement at the tool boundary.
